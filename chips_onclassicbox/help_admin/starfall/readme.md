Описание работы вывода топ-3:
Работает система поинтов - чем больше конкретных действий (там 6 разных проверок) совершил игрок, тем больше у него поинтов.
"white props" - Пропы которые затриггерили антикраш 100%
остальное интуитивно понятно
Так-же выноситься топ 3 по кольву энтити (без счёта пропов), колву пропов и нагрузке чипов E2/SF 

Полная работа топ-3 темы:
Детекция лага:

Канарейка замерзла - проп, который никто не трогает, внезапно заморозился сервером (это значит сервер перегружен физикой)
Проверка кулдауна - с последнего репорта прошло минимум 10 секунд (чтобы не спамить)
Запуск сканирования - начинается поиск виновного

Сбор данных (по 50 энтити за раз):
Перебор всех энтити - проверяется каждый объект на сервере небольшими порциями
Пропуск без владельца - энтити без владельца-игрока игнорируются
Учёт чипов всегда - SF/E2 чипы считаются даже если запаренчены
Пропуск парентнутых - энтити прикреплённые к другим (кроме чипов) пропускаются

Подсчёт для каждого игрока:
Общая статистика:

Всего энтити - сколько объектов принадлежит игроку
Пропы - сколько из них prop_physics
Прочие - всё остальное (разница)

Оценка нагрузки (scoring):

| Constraints (×0.05) - количество связей между объектами (макс 1000)
| Heavy props (×1.5) - пропы тяжелее 500кг
| Recent spawns (×3) - объекты созданные за последние 5 секунд
| White props (×100) - пропы с цветом 255,255,255,100 (сервер помечает лагающие)
| Velocity spikes (×100) - объекты с резким изменением скорости >2000 единиц
| Collisions (×100) - столкновения с другими объектами

Статистика чипов:

CPU usage - нагрузка каждого SF/E2 чипа в микросекундах

Генерация отчёта:

| Расчёт score - суммируются все баллы для каждого игрока
| Сортировка - игроки сортируются по убыванию score
| Топ-3 подозреваемых - выводятся три игрока с наибольшим score и детали
| Топ-3 по энтити - выводятся игроки с наибольшим количеством объектов
| Топ-3 по CPU чипов - выводятся самые нагруженные чипы
| Логирование первого - игрок №1 записывается как lastOffender для спектейта клавишей "h"

После отчёта Канарейка продолжает работу - размораживается и падает дальше

- Страница сохраняется, так что можете спокойно открывать и закрывать меню
- Есть два типа кнопок, под-меню и сами кнопки. Отталкивайтесь от названий
- Кнопка BACK это вернутся из ПОДМЕНЮ
`Функционал`:
Он такой огромный, мне лень писать, но:
- Первая страница
- - Самые дефолт команды быстрого доступа: Noclip, god/ungod, !getlag, !e2tracker
- - кастомная Get physics, выводит в чат по формату Ник кол-во-Пропы кол-во-Чипы
- Вторая страница (нажатие ПКМ/ЛКМ)
- - Cleanup vote, запуск голосования на клинап карты
- - Cleanup, запуск таймера на 120 секунд для клинапа
- - Sslay ^, убить себя
- - Freeze Nearest, зафризить ближайшего к себе игрока

- - Punishments (ПОДМЕНЮ) НАКАЗАНИЯ
- - - на первой странице все первоначальные наказания (джайл, мут, гаг, т.д.) ||(работает через @, так что нажимая смотрите ровно на человека которого хотите наказать!)||
- - - на второй странице все след. наказания (бан, пермабан, т.д.)

- - ESP MENU (ПОДМЕНЮ)

- - - Previous, переключится на предыдущего игрока
